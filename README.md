小星单词

一款基于uni-app的轻量化英语学习小程序，集“中英互译+英语备忘录”于一体，帮助用户在碎片化时间中完成“翻译—积累—检索—复习”的学习闭环。 一、项目简介

在碎片化学习趋势下，英语学习者常面临翻译需求与知识积累割裂的问题：生词、例句零散记录，难以统一管理和高效复习。 “小星单词”以“翻译即积累”为核心设计理念，将中英互译与分类备忘录深度结合，用户在完成翻译的同时即可一键保存优质内容，实现知识的即时沉淀与重复利用，适用于学生及职场人日常英语学习场景。

二、核心功能

中英双向翻译 支持单词、短语、长句的中英互译

智能例句生成 基于讯飞星火 Spark X1.5，根据单词自动生成例句，辅助记忆

英语备忘录 翻译结果可一键存入备忘录，支持编辑与删除

标签与分类管理 自定义标签、分类记录内容，便于长期积累

多条件搜索 支持关键词、分类、标签组合检索

重点标记与收藏 对重要句子进行重点标记或收藏，优先复习

今日好句推送 提供每日优质英文句子，增强学习氛围

三、技术方案

技术栈 前端：uni-app、Vue 2 后端：Node.js 数据库：MySQL 通信方式：uni.request AI / NLP 技术：讯飞星火 Spark X1.5、TF-IDF、关键词匹配、启发式决策策略
技术亮点 翻译界面融合 AI 例句生成，提升单词理解与记忆效率 备忘录支持标签化、多维搜索与重点标记，增强复习针对性 翻译与存储模块深度联动，实现“即查即存”

生成对应英文例句

删除搜索记录
